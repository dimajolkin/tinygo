# TinyGo Project Rules

## Правила для предотвращения ошибки ContextWindowExceededError

### 1. Ограничение контекста запросов
- Максимальный размер контекста: 128000 токенов (безопасный запас от лимита 131072)
- При анализе кода:
  - Разбирать большие файлы по частям
  - Использовать семантический поиск вместо полного чтения всех файлов
  - Ограничивать глубину рекурсии при анализе зависимостей

### 2. Оптимизация запросов
- Использовать конкретные и лаконичные формулировки
- Избегать дублирования информации в запросах
- Запрашивать только необходимые части кода
- Использовать относительные пути вместо абсолютных

### 3. Обработка ошибок
- При получении ошибки ContextWindowExceededError:
  1. Разбить запрос на более мелкие части
  2. Сузить область анализа
  3. Использовать более фокусированные запросы

### 4. Стратегии работы с большими файлами
- Для файлов >1000 строк: читать только необходимые секции
- Использовать search_files для поиска конкретных паттернов
- Анализировать файлы по частям с понятными контекстами

### 5. Конфигурация моделей
- Предпочтительно использовать модели с большим контекстным окном
- Для сложных задач использовать пошаговый подход
- Регулярно очищать контекст между задачами

## Рекомендации

- Рекомендация 1: Всегда начинать анализа с семантического поиска
- Рекомендация 2: Использовать incremental analysis для больших проектов
- Рекомендация 3: Сохранять историю изменений для контекстного анализа
